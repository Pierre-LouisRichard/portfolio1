Stage BTS SIO - 85 Micro

Stage réalisé à La Roche-sur-Yon dans une entreprise spécialisée dans la réparation informatique. Mise en place d’une infrastructure complète virtualisée sous Proxmox avec plusieurs services réseau.

Proxmox AD DNS Zabbix GLPI Virtualisation

Contexte

Stage effectué chez 85 Micro, entreprise spécialisée dans la réparation et maintenance de matériel informatique. L’objectif était de moderniser l’infrastructure interne en mettant en place un environnement virtualisé.

Missions réalisées

  • Installation et configuration d’un serveur Proxmox
  • Création de machines virtuelles
  • Mise en place d’un Active Directory
  • Configuration DNS
  • Déploiement d’un serveur Web
  • Mise en place de Zabbix pour la supervision
  • Installation de GLPI pour la gestion de parc

Infrastructure mise en place

L’infrastructure reposait sur Proxmox permettant de virtualiser plusieurs services :

  • Contrôleur de domaine (Active Directory)
  • Serveur DNS
  • Serveur Web
  • Serveur de supervision Zabbix
  • Serveur GLPI pour la gestion IT

Bilan

Ce stage m’a permis de maîtriser la virtualisation avec Proxmox et de mettre en place une infrastructure complète similaire à celle d’une PME.

J’ai également renforcé mes compétences en administration système et réseau.
