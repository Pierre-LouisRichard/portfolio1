AP4 - Infrastructure réseau d’une mairie

Projet réalisé en binôme consistant à concevoir et simuler une infrastructure réseau complète pour une mairie via Cisco Packet Tracer, intégrant segmentation, sécurité et accès internet.

Cisco VLAN DMZ NAT / PAT Routage Packet Tracer

Contexte

Dans le cadre de l’AP4, nous devions concevoir une infrastructure réseau pour une mairie. Le projet consistait à simuler un environnement complet avec plusieurs sites, une connexion FAI, et une architecture sécurisée.

Missions réalisées

  • Création d’une topologie réseau complète sur Cisco Packet Tracer
  • Configuration de 5 routeurs (FAI, R_EXT, Routeur_A, Routeur_B, R_Prévert)
  • Mise en place de VLAN
  • Configuration NAT / PAT
  • Mise en place d’une DMZ avec serveur Web
  • Configuration des switchs (administrables et non administrables)

Partie personnelle

J’ai réalisé la majorité de l’infrastructure réseau :

  • Configuration des routeurs
  • Création des VLAN
  • Configuration NAT / PAT
  • Mise en place de la DMZ
  • Déploiement du serveur Web

Les parties non réalisées :

  • Active Directory
  • Supervision Zabbix
  • ACL

Architecture

L’infrastructure comprenait :

  • 5 routeurs interconnectés
  • 3 switchs administrables
  • 2 switchs non administrables
  • Plusieurs VLAN pour segmenter le réseau
  • Une DMZ pour isoler le serveur Web

Bilan

Ce projet m’a permis de renforcer fortement mes compétences en réseau, notamment sur la configuration Cisco, la segmentation réseau et la sécurité.

C’est l’un des projets les plus techniques de ma formation.
